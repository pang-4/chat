# Tailscale 설치

공식 설치 스크립트를 실행

```
curl -fsSL https://tailscale.com/install.sh | sh
```

# Tailscale 실행

설치가 끝나면

```
sudo tailscale up
```

아래처럼 나오는 URL을 접속
```
To authenticate, visit:https://login.tailscale.com/......
```

Ubuntu에서 ip확인

```
tailscale status
```

# VS Code 연결

VS Code에서

```
⌘ + Shift + P
```

검색
```
Remote-SSH: Connect to Host...
```

선택
```
Add New SSH Host
```

입력
```
ssh pang@100.xxx.xxx.xxx
```

선택
```
~/.ssh/config
```


```
Host web3-dev   
	 HostName 100.xxx.xxx.xxx
     User pang
```
