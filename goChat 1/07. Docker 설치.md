# 패키지 목록 업데이트

```
sudo apt update
```

Ubuntu 저장소 정보를 최신으로 가져온다.

---

# Docker 저장소를 추가하기 위한 패키지 설치

```
sudo apt install -y ca-certificates curl gnupg
```

- `ca-certificates` : HTTPS 인증서 검증
- `curl` : 인터넷에서 파일 다운로드
- `gnupg` : Docker 저장소의 서명을 검증

---
# Docker 공식 GPG Key 추가

먼저 Docker 저장소를 신뢰할 수 있도록 공개키를 등록한다.

```
sudo install -m 0755 -d /etc/apt/keyrings

curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

sudo chmod a+r /etc/apt/keyrings/docker.gpg
```

### 왜 필요한가?

Ubuntu는 아무 저장소나 믿지 않는다.
Docker에서 제공한 프로그램이 맞는지 **전자서명(GPG)** 을 검증하기 위해 공개키를 등록하는 것이다.

---

# Docker 공식 저장소 추가

```
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

### 왜 필요한가?

기본 Ubuntu 저장소에는 Docker가 항상 최신 버전이 있는 것은 아니다.

우리는 **Docker 공식 저장소**에서 최신 안정 버전을 설치한다.

# Docker 설치

패키지 목록을 다시 갱신한 뒤 설치한다.

```
sudo apt update

sudo apt install -y \
docker-ce \
docker-ce-cli \
containerd.io \
docker-buildx-plugin \
docker-compose-plugin
```

- `docker-ce` : Docker Engine
- `docker-ce-cli` : Docker 명령어
- `containerd` : 컨테이너 실행 엔진
- `buildx` : Docker 이미지 빌드 기능
- `compose-plugin` : `docker compose` 기능

---

## 설치가 끝나면 바로 확인

```
docker --version
docker compose version
```
