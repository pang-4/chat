# Go Kubernetes DevOps Portfolio

## 프로젝트명
**Go WebSocket 기반 대규모 실시간 서버 운영 프로젝트**

## 프로젝트 소개

Go의 동시성(Goroutine, Channel)을 활용하여 대규모 WebSocket 서버를 구축하고, Docker와 Kubernetes 환경에서 운영하며 대량의 사용자와 메시지 트래픽을 처리하는 과정을 경험하는 것

단순히 애플리케이션을 개발하는 것이 아니라 Docker를 이용한 컨테이너화, Kubernetes를 이용한 오케스트레이션, GitHub Actions와 ArgoCD를 이용한 CI/CD 및 GitOps 환경 구축, Prometheus와 Grafana를 이용한 모니터링, k6를 이용한 부하 테스트까지 전체 운영 과정을 직접 구현하는 것을 목표로 합니다.

---

# 프로젝트 목표

- Go 기반 WebSocket 서버 개발
- Docker를 이용한 컨테이너 이미지 생성
- Kubernetes(Minikube) 환경에 애플리케이션 배포
- GitHub Actions를 이용한 CI 구축
- ArgoCD를 이용한 GitOps 기반 CD 구축
- Prometheus + Grafana를 이용한 모니터링
- k6를 이용한 부하 테스트
- DevOps 전체 흐름 이해 및 포트폴리오 제작
