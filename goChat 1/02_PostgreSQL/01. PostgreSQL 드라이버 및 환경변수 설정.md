# pgx

```
go get github.com/jackc/pgx/v5
```

PostgreSQL과 대화하기 위한 라이브러리

비유하면

```
Go
   │
   │  (한국어)
   ▼
pgx
   │
   │  (PostgreSQL 언어)
   ▼
PostgreSQL
```

Go는 PostgreSQL과 직접 대화하는 방법을 모른다.

통역사가 필요한데 그게 `pgx`다.

나중에

```
db.Exec(...)
db.Query(...)
db.QueryRow(...)
```

같은 것들이 전부 이 라이브러리를 통해 PostgreSQL과 통신한다.

# ② godotenv

```
go get github.com/joho/godotenv
```

`.env` 파일을 읽는 라이브러리

비유하면

```
.env

DB_HOST=localhost
DB_USER=postgres
```

↓

```
godotenv

↓

운영체제 환경변수 등록
```

↓

```
os.Getenv("DB_HOST")
```

즉,

`.env`를 읽어서

Go가 사용할 수 있도록 환경변수로 등록해 주는 역할이다.

---
나중에 Kubernetes에 배포할 때는 조금 달라진다.

- `pgx`는 계속 사용한다. PostgreSQL과 통신해야 하니까.
- `godotenv`는 개발용으로만 사용하는 경우가 많다.  운영 환경에서는 Kubernetes가 환경변수를 직접 주입해 주기 때문에 `.env` 파일이 없어도 같은 코드(`os.Getenv`)가 동작한다.

즉, `pgx`는 "DB와 대화하는 라이브러리", `godotenv`는 "개발할 때 `.env`를 읽어주는 편의 라이브러리"라고 기억하면 된다.
