# Git 설치 확인

git 버전 확인

```
git --version
```

만약 설치가 안되어있다면 
```
sudo apt update
sudo apt install git -y
```

# Git 사용자 정보 등록

GitHub 계정 이름과 이메일을 등록

이름
```
git config --global user.name "이름"
```

이메일
```
git config --global user.email "깃허브 이메일"
```

예시

```
git config --global user.email "abc@gmail.com"
```

확인

```
git config --global --list
```

예시

```
user.name=pang-4
user.email=abc@gmail.com
```



# SSH 키 생성

편의성과 보안성을 위해

```
ssh-keygen -t ed25519 -C "깃허브 이메일"
```

예시

```
ssh-keygen -t ed25519 -C "abc@gmail.com"
```

를 치면 아래가 나온다

```
Enter file in which to save the key
```

그러면 엔터를 누르고
```
Enter
```

아래가 나와도 엔터를 누른다  (아래는 비밀번호 설정)
```
Enter passphrase
```

그냥 Enter 두 번 눌러도 된다.  (개인 개발이라 비밀번호를 생성안되도 된다고 판단)


```
~/.ssh/id_ed25519
```

# SSH 공개키 확인

```
cat ~/.ssh/id_ed25519.pub
```

아래 긴문자열이 나온다 (공개키)
```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA...
```
