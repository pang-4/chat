## 목표

Go의 표준 라이브러리(`net/http`)를 사용하여 가장 기본적인 HTTP 서버를 만들어본다.

## 핵심 개념

### HTTP Server

클라이언트(브라우저)의 요청(Request)을 받아 응답(Response)을 보내는 프로그램이다.

---

### Handler

특정 URL로 요청(Request)이 들어왔을 때 실행되는 함수이다.

예를 들어

```
func helloHandler(w http.ResponseWriter, r *http.Request) {	
	fmt.Fprintln(w, "Hello Go Server!")
}
```
브라우저가 요청을 보내면

```
GET / ->  helloHandler()
```

---

### Routing

URL과 Handler를 연결하는 작업

```
http.HandleFunc("/", helloHandler)
```

의 의미는

```
"/"로 요청하면 helloHandler 실행
```

이다.

라우터는 어떤 URL이 어떤 Handler를 실행할지 결정하는 역할
어떤 URL을 어떤 Handler와 연결할지 결정


---

### ListenAndServe

서버를 실행하고 지정한 포트를 열어 클라이언트의 요청을 계속 기다린다.
HTTP 서버를 실행하고 지정한 포트를 연다

```
http.ListenAndServe(":8080", nil)
```
8080 포트를 열고 브라우저 요청을 계속 기다린다는 의미

---

## 요청 처리 흐름

```
브라우저 -> GET / -> HTTP Server -> Router -> Handler -> Response -> 브라우저
```

---

### 코드 이해
## helloHandler

```
func helloHandler(w http.ResponseWriter, r *http.Request) {	
	fmt.Fprintln(w, "Hello Go Server!")
}
```

브라우저 요청을 처리하는 함수



```
helloHandler(응답통로, 요청정보)
```

# r (Request) : 브라우저가 보낸 요청

```
r *http.Request
```

`r`은 브라우저가 서버에게 보낸 모든 정보가 들어있는 객체

예를 들어 브라우저가

```
http://localhost:8080/login?id=10
```

으로 접속했다면 `r` 안에

- URL (어떤 주소로 왔는지 (`/login`))
- GET / POST
- Query Parameter (예: ?id=10  (? 뒤에 전달되는 값))
- Header (헤더정보)
- Cookie
- Body

# w (ResponseWriter) : 브라우저에게 답장을 보내는 통로

```
w http.ResponseWriter
```

`w`는 브라우저에게 응답(Response)을 보내는 역할
