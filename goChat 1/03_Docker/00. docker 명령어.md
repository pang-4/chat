## 컨테이너 실행

```
docker compose up -d
```

---
## 컨테이너 종료

```
docker compose down
```
---
## 실행 중인 컨테이너 보기

```
docker ps
```
---
## 모든 컨테이너 보기

```
docker ps -a
```

종료된 컨테이너까지 모두 본다

---
## 로그 보기

```
docker logs chat-postgres
```

또는

```
docker compose logs
```

오류가 나면 가장 먼저 보는 명령어

---
## 컨테이너 내부 들어가기

```
docker exec -it chat-postgres bash
```

PostgreSQL 안으로 들어간다

---
## 이미지 보기

```
docker images
```

다운로드된 이미지 목록을 본다.

---
## Volume 보기

```
docker volume ls
```

데이터 저장 공간 확인
