
```
services:
  postgres:
    image: postgres:17

    container_name: chat-postgres

    restart: unless-stopped

    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: chat

    ports:
      - "5432:5432"

    volumes:
      - postgres-data:/var/lib/postgresql/data

volumes:
  postgres-data:
```

# services:
- 실행할 컨테이너(프로그램) 목록
```
services:
  postgres:
  redis:
  prometheus:
  grafana:
```
나중에는 여러개가 붙을 수도 있다

# postgres:

- 이름을 다르게 해도되지만 보통 바꾸진않는것 같다.

# image:
Docker는

```
Docker Hub
    │
    ▼
postgres:17 이미지 다운로드
    │
    ▼
컨테이너 생성
```

이 순서로 동작한다.

```
image: postgres:17
```

은  PostgreSQL 17 이미지를 사용하라는 의미

---

# container_name

컨테이너 이름을 만약 안 쓰면 Docker가
```
hopeful_morse

happy_cat

nice_lion
```

같은 랜덤 이름을 만든다.

```
chat-postgres
```

라는 이름을 직접 붙여서 관리하기 쉽게 만든 것이다.

---
# restart

```
restart: unless-stopped
```

Ubuntu가 재부팅되거나 Docker가 다시 시작되면 PostgreSQL도 자동으로 다시 실행하라는 의미다

만약 이게 없다면 Ubuntu를 재부팅한 뒤
```
docker compose up
```
를 다시 입력해야 한다.

---
# environment

이건 PostgreSQL에게 초기 설정값을 전달하는 부분이다.

예를 들어

```
POSTGRES_USER: postgres
```

↓

처음 생성되는 계정

```
postgres
```

---

```
POSTGRES_PASSWORD: postgres
```

↓

비밀번호

```
postgres
```

---

```
POSTGRES_DB: chat
```

↓

처음 생성되는 데이터베이스

```
chat
```

---

즉 처음 실행하면

```
Database

chat
```
가 자동으로 만들어진다.

---
# ports

```
ports:
  - "5432:5432"
    우분투 : 컨테이너
```

그림으로 보면

```
Ubuntu

5432
 │
 │ 연결
 ▼

Docker(PostgreSQL)

5432
```

그래서 Go는

```
localhost:5432
```

로 접속하면 Docker 안의 PostgreSQL에 연결된다

---
# volumes

```
volumes:
  - postgres-data:/var/lib/postgresql/data
```
데이터가 저장되는 곳이다.

만약 이게 없다면
```
컨테이너 삭제

↓

모든 데이터 삭제
```
가 된다.

하지만 Volume이 있으면
```
컨테이너 삭제

↓

데이터 유지
```
가 된다.

그래서 실제 프로젝트에서는 거의 항상 Volume을 사용한다.

---
# 마지막 volumes

```
volumes:
  postgres-data:
```

여기서

```
postgres-data
```

라는 저장 공간(Volume)을 하나 만들어 달라는 뜻이다.

Docker가 자동으로 관리해 준다.
