## 목적

미니 PC를 다시 켰거나 Minikube를 중지한 뒤, Kubernetes와 운영 도구에 다시 접속할 때 사용하는 명령어를 정리한다.

ArgoCD와 Grafana는 Kubernetes 안에서 Pod로 실행된다. 브라우저에서 접속하려면 Minikube를 먼저 시작한 뒤 각각 Port Forward를 실행해야 한다.

---

## 전체 실행 순서

```text
Minikube 시작
→ Kubernetes Pod 상태 확인
→ ArgoCD Port Forward
→ Grafana Port Forward
→ 브라우저 접속
```

---

## 1. Minikube 시작

```bash
minikube start
```

상태 확인:

```bash
minikube status
```

정상 상태:

```text
host: Running
kubelet: Running
apiserver: Running
kubeconfig: Configured
```

전체 Kubernetes Pod 확인:

```bash
kubectl get pods -A
```

주요 Namespace별 확인:

```bash
kubectl get pods -n chat
kubectl get pods -n argocd
kubectl get pods -n monitoring
```

---

## 2. ArgoCD 접속

새 터미널에서 실행한다.

```bash
kubectl port-forward \
  --address=100.126.215.15 \
  service/argocd-server \
  8443:443 \
  -n argocd
```

브라우저 접속:

```text
https://100.126.215.15:8443
```

초기 관리자 비밀번호를 다시 확인해야 할 때:

```bash
kubectl get secret argocd-initial-admin-secret \
  -n argocd \
  -o jsonpath='{.data.password}' \
  | base64 --decode

echo
```

```text
Username: admin
Password: 위 명령으로 확인한 값
```

초기 비밀번호를 변경한 뒤에는 변경한 비밀번호를 사용한다.

---

## 3. Grafana 접속

ArgoCD Port Forward가 실행 중인 터미널과 별개의 새 터미널에서 실행한다.

```bash
kubectl port-forward \
  --address=100.126.215.15 \
  service/monitoring-grafana \
  3000:80 \
  -n monitoring
```

브라우저 접속:

```text
http://100.126.215.15:3000
```

Grafana 관리자 비밀번호 확인:

```bash
kubectl get secret monitoring-grafana \
  -n monitoring \
  -o jsonpath='{.data.admin-password}' \
  | base64 --decode

echo
```

```text
Username: admin
Password: 위 명령으로 확인한 값
```

---

## 4. Prometheus 화면이 필요할 때

Prometheus Target이나 PromQL을 직접 확인할 때만 실행한다.

```bash
kubectl port-forward \
  --address=100.126.215.15 \
  service/monitoring-kube-prometheus-prometheus \
  9090:9090 \
  -n monitoring
```

브라우저 접속:

```text
http://100.126.215.15:9090
```

Target 확인:

```text
http://100.126.215.15:9090/targets
```

---

## 5. 채팅 서비스에 접속할 때

```bash
kubectl port-forward \
  --address=100.126.215.15 \
  service/chat-app \
  8080:8080 \
  -n chat
```

WebSocket 접속 주소:

```text
ws://100.126.215.15:8080/ws
```

---

## Port Forward와 Pod의 차이

Port Forward는 외부 PC에서 Kubernetes Service로 들어가기 위한 임시 접속 통로다.

```text
Mac 브라우저
→ 미니 PC의 Port Forward
→ Kubernetes Service
→ Pod
```

Port Forward 터미널에서 `Ctrl+C`를 누르면 해당 접속 통로만 종료된다. Kubernetes Pod나 Minikube가 종료되는 것은 아니다.

```text
Ctrl+C
→ 브라우저 접속 통로 종료
→ ArgoCD, Grafana, Chat Pod는 계속 실행
```

각 Port Forward 명령은 실행 중인 터미널을 계속 사용하므로 ArgoCD, Grafana, Prometheus, Chat 연결은 서로 다른 터미널에서 실행한다.

---

## Minikube를 종료할 때

클러스터 상태를 보존하면서 중지:

```bash
minikube stop
```

다시 사용할 때:

```bash
minikube start
```

`minikube delete`는 클러스터 자체를 삭제하므로 단순 종료 목적으로 사용하지 않는다.
