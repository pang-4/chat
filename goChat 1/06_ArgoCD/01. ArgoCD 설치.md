# ArgoCD 설치

## ArgoCD를 사용하는 이유

ArgoCD는 Git에 기록된 Kubernetes 설정을 원하는 상태로 보고, 실제 Cluster 상태와 비교하여 동기화하는 GitOps CD 도구다.

```text
Git의 k8s YAML
→ ArgoCD가 읽음
→ 실제 Kubernetes 상태와 비교
→ 차이가 있으면 동기화
→ Kubernetes가 Pod Rolling Update
```

Kubernetes가 Git을 직접 읽거나 YAML을 수정하는 것은 아니다.

```text
GitHub Actions = 코드 검사, 이미지 생성, 배포 버전 기록
ArgoCD         = Git 변경 감지와 Kubernetes 적용
Kubernetes     = 실제 Pod 생성·교체·복구
```

---

## 설치 환경

```text
Cluster: Minikube 단일 Node
ArgoCD: v3.4.2
설치 유형: Non-HA
Namespace: argocd
```

학습용 단일 Node Cluster이므로 여러 ArgoCD Replica를 사용하는 HA 설치 대신 일반 설치를 사용하였다.

---

## Namespace 생성

```bash
kubectl create namespace argocd
```

확인:

```bash
kubectl get namespace argocd
```

---

## ArgoCD 설치

운영 중 버전이 의도하지 않게 바뀌지 않도록 `stable` 주소 대신 버전을 고정하였다.

```bash
kubectl apply \
  -n argocd \
  --server-side \
  --force-conflicts \
  -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.4.2/manifests/install.yaml
```

| 옵션 | 의미 |
|---|---|
| `-n argocd` | ArgoCD 자원을 argocd Namespace에 설치 |
| `--server-side` | 큰 CRD 설정을 API Server에서 처리 |
| `--force-conflicts` | 설치 Manifest가 관리하는 필드 충돌 해결 |
| `-f URL` | 공식 설치 Manifest 사용 |

## Pod 상태 확인

```bash
kubectl get pods -n argocd -w
```

관찰한 상태 변화:

```text
ContainerCreating
→ PodInitializing
→ Running
→ 1/1 Running
```

모든 Pod가 `1/1 Running`이 된 뒤 `Ctrl+C`로 Watch를 종료하였다.

---

## 주요 구성요소

| Pod | 역할 |
|---|---|
| `argocd-server` | Web UI와 API 제공 |
| `argocd-application-controller` | Git과 실제 Cluster 상태 비교·동기화 |
| `argocd-repo-server` | Git 저장소에서 Manifest 읽기 |
| `argocd-applicationset-controller` | 여러 Application 자동 생성·관리 |
| `argocd-dex-server` | 외부 로그인·인증 연동 |
| `argocd-notifications-controller` | 배포 알림 처리 |
| `argocd-redis` | ArgoCD 내부 Cache |

`argocd/redis`는 채팅 메시지를 전달하는 `chat/redis`와 서로 다른 Namespace의 별도 Redis다.

## 초기 관리자 비밀번호

```bash
kubectl get secret argocd-initial-admin-secret \
  -n argocd \
  -o jsonpath='{.data.password}' \
  | base64 -d
```

초기 사용자 이름:

```text
admin
```

비밀번호는 문서나 Git에 기록하지 않는다.

## Tailscale을 통한 Web UI 접속

미니 PC에서:

```bash
kubectl port-forward \
  --address=100.126.215.15 \
  service/argocd-server \
  -n argocd \
  8443:443
```

Mac 브라우저:

```text
https://100.126.215.15:8443
```

ArgoCD 기본 인증서는 자체 서명 인증서이므로 브라우저 보안 경고가 표시될 수 있다. Port Forward 터미널을 종료하면 접속도 종료된다.
